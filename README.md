# English Cards

Минимальное Android-приложение для интервального повторения английских слов.

- Android 16 / targetSdk 36
- более 1000 встроенных карточек
- 4 оценки: Снова / Трудно / Хорошо / Легко
- локальная SQLite база и сохранение прогресса
- 20 новых слов в день по умолчанию
- импорт CSV/TSV
- полностью офлайн

## Интервальное повторение

- Снова — возвращает слово в текущую сессию примерно через минуту.
- Трудно — короткий интервал.
- Хорошо — обычный рост интервала.
- Легко — увеличенный интервал.

## Импорт слов

Поддерживается UTF-8 CSV/TSV. Две колонки: английское слово и русский перевод. Пример есть в `sample-import.csv`.

## APK

GitHub Actions собирает debug APK и публикует его как artifact `EnglishCards-apk`.
